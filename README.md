MultiLanguageGenerate 是一款基于 Golang 的，高并发 多语言 多格式 翻译文件生成器。

支持 `Docx` `Xlsx` 等字节流文件。


## 核心特性
**高并发**: 利用Golang的高并发特性开发。

**多类型**: 匹配多种文件类型，包括docx、xlsx等，更灵活更省心的进行翻译。

**AI驱动**: 利用 LLM API，进行翻译。
